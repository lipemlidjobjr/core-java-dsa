## Projects in this Repo

### 1. DiceRoller.java
A Java implementation of a uniform probability distribution (1-6).
- Built to understand 'java.util.Random' and object instantiation.\

### 2. dice_stats.py
A Python simulation of the **Law of Large Numbers**.
- Rolls a virtual die 10,000 times.
- Calculates the convergence of empirical probability to theoretical probability (16.67%).

## Tech Stack
- **Languages:** Java 21, Python 3.14
- **Environment:** WSL2 (Ubuntu)
- **OS:** Windows 11 (Host)

## How to Run
1. Clone the repository.
2. For Java: 'javac DiceRoller.java && java DiceRoller'
3. For Python: 'python3 dice_stats.py'
